# 🔐 Tokeniser

> The model never sees who you are.

## What I do

Replaces phone numbers, card numbers, VPAs, account numbers, PAN and Aadhaar with format-preserving tokens before any model reads the text.

## Rules I keep

- Only the Tool Gateway can turn a token back into the real value, and only when a tool runs.
